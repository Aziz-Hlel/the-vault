- If you plan to keep your application primarily hosted on AWS, **Amazon Linux** is the standard default, it's the best default choice for AWS
- **Pros:** Pre-configured with the AWS CLI, SSM Agent (allows logging in via browser without SSH keys), and optimized AWS drivers out of the box. It is lightweight, fast-booting, and backed by AWS support.
